# RegIntel、RiskGraph与ControlPulse评测证据

运行日期：2026-08-11。所有数据均为固定种子生成或人工编写的合成演示数据。

## RegIntel混合检索

- 语料：8份合成税务演示文档。
- 查询：12条人工编写查询。
- 排序：二元词项分数与字符2-4 gram TF-IDF余弦相似度加权。
- 实测：Recall@3 = 1.0000；MRR = 1.0000。

该集合规模小且与语料同源，只能证明评测管线和基础检索能力，不能作为真实法规问答准确率。下一步需引入公开法规、同义改写、困难负例、时间版本和人工引用核验。

## RiskGraph时间切分模型

- 数据：400个合成实体、12个月、4,800个实体-月份样本。
- 切分：月份1-8训练（3,200行），月份9-12测试（1,600行）。
- 测试阳性率：5.375%。
- 模型：180棵随机森林；输入8项图和行为特征。
- Average Precision：0.862674。
- ROC-AUC：0.922464。
- Recall@Top 5%：0.837209。
- 阈值0.5：Precision 1.000000；Recall 0.837209。

模型与模型卡位于`artifacts/risk-model-v1/`，`manifest.json`记录字节数和SHA-256。Phase 3另完成实体隔离时间外验证：299个训练实体、101个留出实体，实体交叉数为0；PR-AUC 0.869943、ROC-AUC 0.894092，8项特征最大PSI 0.054440。标签由合成机制产生，这些指标不能代表真实舞弊识别效果。

## ControlPulse事件流

- 输入：3条合成事件。
- 偏移量：0-2连续。
- 处理：3条；产生5个控制案件。
- 流验证：哈希链有效，共3条记录。
- 已通过自动化测试：分批消费、检查点恢复、全量回放不重复产生案件、篡改检测。

JSONL是Redpanda/Kafka之前的本地开发适配器。它证明偏移量、幂等、回放和完整性语义，但不证明分布式吞吐、分区顺序或故障转移能力。
